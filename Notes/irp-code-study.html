🌊 Thermoviscous Channel Flow

2D Incompressible Navier-Stokes in Streamfunction-Vorticity Form

Overview

This code simulates thermoviscous fluid flow in a 2D microchannel. It solves the incompressible Navier-Stokes equations using a streamfunction-vorticity formulation on a structured finite-difference grid.

What it does: A parabolic inlet velocity profile (Poiseuille flow) is modulated by two sinusoidal signals (2 Hz and 3 Hz). The fluid passes through "thermal strips" with different viscosities, and the code tracks how the frequency content evolves at the outlet.
FeatureImplementation
Spatial discretizationFinite differences, node-based
Time integrationExplicit Euler (forward in time)
Poisson solverSparse LU factorization (pre-factored)
Boundary conditionsDirichlet on all walls, zero-gradient at inlet/outlet for ω
Thermal effectSpatially varying viscosity field ν(x,y)

1. Parameters

All simulation constants are defined at the top. The domain is a 10 mm × 2.5 mm channel.

Strip Geometry

Four rectangular strips are placed inside the channel. Each strip can have a different viscosity multiplier (STRIP_NU_FRAC). When frac = 1.0, the strip has the same viscosity as the surrounding fluid.

3. Grid Initialization

Two primary fields are allocated:

  • ψ (psi) — streamfunction, scalar potential whose derivatives give velocity
  • ω (omega) — vorticity, the curl of velocity (∂v/∂x − ∂u/∂y)

The viscosity field nu is initialized as a uniform field, then overwritten inside each strip region.

📄 Grid init code ▼ 
psi = np.zeros((NX + 1, NY + 1))
nu = np.ones((NX + 1, NY + 1)) * NU_COLD
for i, frac in enumerate(STRIP_NU_FRAC):
    x0 = STRIP_X_STARTS[i]
    nu[x0:x0+STRIP_WIDTH+1, STRIP_Y_START:STRIP_Y_START+STRIP_HEIGHT+1] = NU_COLD * frac

3. Poisson Solver

At every timestep, we solve:

∇²ψ = −ω

This is the Poisson equation that links streamfunction to vorticity. Because the grid is fixed, we pre-build and LU-factorize the Laplacian matrix once — a huge speedup.

Building the Laplacian Matrix

The 5-point Laplacian stencil for an interior node (i, j) is assembled into a sparse CSR matrix. Dirichlet boundary conditions are handled by moving boundary terms to the RHS.

📄 Poisson solver code ▼ 
def build_poisson_matrix(nx, ny, dx, dy):
    n_int = (nx - 2) * (ny - 2)
    data, row_idx, col_idx = [], [], []
    def add_entry(r, c, val):
        row_idx.append(r); col_idx.append(c); data.append(val)
    nxi = nx - 2
    for j in range(1, ny - 1):
        for i in range(1, nx - 1):
            r = (j - 1) * nxi + (i - 1)
            diag = -2.0/(dx*dx) - 2.0/(dy*dy)
            add_entry(r, r, diag)
            if i > 1: add_entry(r, r-1, 1.0/(dx*dx))
            if i < nx-2: add_entry(r, r+1, 1.0/(dx*dx))
            if j > 1: add_entry(r, r-nxi, 1.0/(dy*dy))
            if j < ny-2: add_entry(r, r+nxi, 1.0/(dy*dy))
    return sparse.csr_matrix((data,(row_idx,col_idx)), shape=(n_int,n_int))

PoissonMat = build_poisson_matrix(NX+1, NY+1, DX, DY)
PoissonLU = splu(PoissonMat)  # ← pre-factorize once

solve_streamfunction()

This subtracts boundary contributions from the RHS, solves for interior ψ, then reconstructs the full field with Dirichlet BCs applied on all edges.

Watch out: The RHS array uses Fortran ordering (order='F') because the sparse matrix was built with i varying fastest. C-order (flatten()) would misalign the vector and matrix, causing the solver to return garbage. After solving, reshape back with the same ordering.
📄 solve_streamfunction code ▼ 
def solve_streamfunction(omega, psi_bcs):
    rhs = -omega[1:-1, 1:-1].copy()
    rhs[:, 0]  -= psi_bcs['bottom'][1:-1] / (DY*DY)
    rhs[:, -1] -= psi_bcs['top'][1:-1]    / (DY*DY)
    rhs[0, :]  -= psi_bcs['left'][1:-1]   / (DX*DX)
    rhs[-1, :] -= psi_bcs['right'][1:-1]  / (DX*DX)

    psi_int = PoissonLU.solve(rhs.flatten(order='F'))
    psi_int = psi_int.reshape((NX-1, NY-1), order='F')

    psi_full = np.zeros((NX+1, NY+1))
    psi_full[1:-1, 1:-1] = psi_int
    psi_full[0, :] = psi_bcs['left']
    psi_full[-1, :] = psi_bcs['right']
    psi_full[:, 0] = psi_bcs['bottom']
    psi_full[:, -1] = psi_bcs['top']
    return psi_full

4. Helper Functions

ramp(t)

Smoothly ramps the inlet from 0 to full amplitude over RAMP_TIME using a cosine half-period. Avoids sharp transients at startup.

ramp(t) = 0.5 · (1 − cos(π·t / t_ramp)) for t < t_ramp, else 1.0

inlet_psi_profile(t)

Constructs the inlet streamfunction profile ψ(y). It has two parts:

  1. Parabolic (Poiseuille) part: from integrating the parabolic velocity profile
  2. Signal part: two superposed sine waves modulating the flow
ψ_parab(y) = U_max · (2y²/H − 4y³/(3H²))
ψ_full(y,t) = ψ_parab(y) + ramp(t) · A_amp · [sin(2π·2·t) + sin(2π·3·t)] · y

velocity_from_psi(psi)

Recovers velocity components from ψ using central differences:

u = ∂ψ/∂y, v = −∂ψ/∂x

One-sided differences are used on the boundaries where central differences would reach outside the domain.

vorticity_rhs(omega, psi, nu)

This is the vorticity transport equation right-hand side:

∂ω/∂t = −u·∂ω/∂x − v·∂ω/∂y + ν·∇²ω

Which is: −advection + diffusion. The function computes this on interior nodes only (1:-1, 1:-1).

📄 Helper functions code ▼ 
def ramp(t):
    if t >= RAMP_TIME: return 1.0
    return 0.5 * (1.0 - np.cos(np.pi * t / RAMP_TIME))

def inlet_psi_profile(t):
    y = np.arange(NY + 1) * DY
    psi_parab = U_MAX * (2.0*y**2/H - 4.0*y**3/(3.0*H**2))
    r = ramp(t)
    signal = A_AMP * (np.sin(2*np.pi*F1*t) + np.sin(2*np.pi*F2*t+np.deg2rad(PHASE_DEG)))
    return psi_parab + r * signal * y

def velocity_from_psi(psi):
    u = np.zeros_like(psi); v = np.zeros_like(psi)
    u[:,1:-1] = (psi[:,2:] - psi[:,:-2]) / (2.0*DY)
    v[1:-1,:] = -(psi[2:,:] - psi[:-2,:]) / (2.0*DX)
    # one-sided on boundaries...
    return u, v

def vorticity_rhs(omega, psi, nu):
    # velocities at interior nodes
    u =  (psi[1:-1,2:] - psi[1:-1,:-2]) / (2.0*DY)
    v = -(psi[2:,1:-1] - psi[:-2,1:-1]) / (2.0*DX)
    # gradients
    dwdx = (omega[2:,1:-1] - omega[:-2,1:-1]) / (2.0*DX)
    dwdy = (omega[1:-1,2:] - omega[1:-1,:-2]) / (2.0*DY)
    # advection + diffusion
    adv = u*dwdx + v*dwdy
    diff = nu * ((omega[2:,1:-1]-2*omega[1:-1,1:-1]+omega[:-2,1:-1])/(DX*DX)
                 + (omega[1:-1,2:]-2*omega[1:-1,1:-1]+omega[1:-1,:-2])/(DY*DY))
    w = np.zeros_like(omega)
    w[1:-1,1:-1] = -adv + diff
    return w

5. Initialization

The initial condition is a steady parabolic flow. ψ is tiled across the domain, and ω is derived from the discrete Laplacian of ψ.

Thom's Formula (Wall Vorticity)

For a no-slip wall, the vorticity is not zero — it must be computed from the wall-adjacent ψ. Thom's formula gives:

ω_wall = −2 · ψ₁ / Δy² (bottom wall)
ω_wall = −2 · (ψ_{N−1} − ψ_N) / Δy² (top wall)

This is a 2nd-order accurate boundary condition derived from a Taylor expansion of ψ at the wall.

Initialization matters: ψ must be initialized as a fully developed parabolic profile across the entire domain (not just boundaries). If ψ_interior = 0 while ψ_wall ≠ 0, Thom's formula generates a huge vorticity mismatch at the corners and the solver blows up instantly.
📄 Initialization code ▼ 
psi_init = inlet_psi_profile(0.0)
psi = np.tile(psi_init, (NX + 1, 1))

omega = np.zeros((NX + 1, NY + 1))
omega[:,1:-1] = -(psi[:,2:] - 2.0*psi[:,1:-1] + psi[:,:-2]) / (DY*DY)
# Thom's formula for wall vorticity
omega[:,0]   = -2.0 * psi[:,1] / (DY*DY)
omega[:,-1]  = -2.0 * (psi[:,-2] - psi[:,-1]) / (DY*DY)

6. Main Time Loop

The timestepping follows this explicit fractional-step order:

  1. Apply BCs to ψ (inlet, outlet, top, bottom)
  2. Solve Poisson ∇²ψ = −ω for the new ψ
  3. Update wall vorticity using Thom's formula from the new ψ
  4. Set inlet/outlet ω to zero-gradient (open boundary)
  5. Compute vorticity RHS (advection + diffusion)
  6. Update interior ω explicitly: ω_new = ω_old + DT · RHS
Order matters! The code first solves Poisson for ψ, then uses the new ψ to compute wall ω. This avoids a 1-step lag that existed in an earlier version.

Open Boundary Vorticity

At the inlet and outlet (open boundaries, not physical walls), we do not use Thom's formula. Instead, we impose a zero-gradient condition:

ω_inlet = ω₁ (zero-gradient in x)
ω_outlet = ω_{N−1} (zero-gradient in x)

This lets vorticity advect smoothly through the open boundaries rather than forcing it to zero.

Stability Check

Two key numbers are printed at startup:

  • CFL = U_max · DT / DX — must be < ~1 for explicit advection stability
  • Diffusion limit = DX² / (4·ν) / DT — must be > ~1 for explicit diffusion stability
📄 Time loop code ▼ 
for n in range(NT):
    t = n * DT
    psi_in = inlet_psi_profile(t)
    psi_top = psi_in[-1]
    psi_bcs = {
        'left': psi_in,
        'right': psi_in,
        'bottom': np.zeros(NX + 1),
        'top': np.ones(NX + 1) * psi_top,
    }
    # 1. Solve Poisson for psi from current omega
    psi = solve_streamfunction(omega, psi_bcs)
    # 2. Wall vorticity from NEW psi
    omega[:,0]  = -2.0 * psi[:,1] / (DY*DY)
    omega[:,-1] = -2.0 * (psi[:,-2] - psi[:,-1]) / (DY*DY)
    # 3. Open boundaries: zero-gradient
    omega[0,:]  = omega[1,:]
    omega[-1,:] = omega[-2,:]
    # 4. Compute RHS and update
    rhs = vorticity_rhs(omega, psi, nu[1:-1,1:-1])
    omega[1:-1,1:-1] += DT * rhs[1:-1,1:-1]
    # 5. Record outlet centerline velocity every N steps
    if n % RECORD_EVERY == 0:

FFT Analysis

The code discards the first half of the signal (transient) and FFTs the rest. The target frequencies (2 Hz and 3 Hz) are located by finding the nearest bin:

f_idx = argmin |freqs − F_target|

The ratio of amplitudes tells you how much the nonlinear thermoviscous effect has altered the frequency mixing.

Note on diffusion: The code uses diff = nu * ∇²ω, which is correct for uniform viscosity. If strips have different ν values, the full thermoviscous diffusion is ∇·(ν∇ω) and requires face-flux discretization.
📄 Post-processing code ▼ 
# FFT on second half (discard transient)
t0 = n_record // 2
u_fft = u_outlet_center[t0:]
dt_rec = DT * RECORD_EVERY
freqs = np.fft.rfftfreq(len(u_fft), d=dt_rec)
spec = np.abs(np.fft.rfft(u_fft))

f1_idx = np.argmin(np.abs(freqs - F1))
f2_idx = np.argmin(np.abs(freqs - F2))
p1 = spec[f1_idx]
p2 = spec[f2_idx]

print(f"2 Hz amplitude: {p1:.4e}")
print(f"3 Hz amplitude: {p2:.4e}")
print(f"2 Hz / 3 Hz ratio:  {p1/p2:.4f}")

Appendix: Streamfunction ψ

For 2D incompressible flow, the continuity equation ∇·u = 0 is automatically satisfied if we define:

u = ∂ψ/∂y, v = −∂ψ/∂x

ψ is a scalar field. Lines of constant ψ are streamlines — the paths fluid particles follow.

Appendix: Vorticity ω

Vorticity is the curl of velocity. In 2D, only the z-component is non-zero:

ω = ∂v/∂x − ∂u/∂y

Substituting the streamfunction definitions gives the Poisson equation:

∇²ψ = −ω

This is the fundamental link between ψ and ω that the solver exploits.

Appendix: Reynolds Number

Re = U·L/ν characterizes the ratio of inertial to viscous forces. Here Re = 10, which is laminar flow — viscous effects dominate, and the flow is stable.

Appendix: LU Factorisation

LU factorisation decomposes a matrix A into a lower-triangular matrix L (with 1s on the diagonal) and an upper-triangular matrix U:

A = L · U

What L and U look like

For a 3×3 system, the decomposition looks like this:

⎡ a₁₁ a₁₂ a₁₃ ⎤ ⎡ 1 0 0 ⎤ ⎡ u₁₁ u₁₂ u₁₃ ⎤
⎢ a₂₁ a₂₂ a₂₃ ⎥ = ⎢ l₂₁ 1 0 ⎥ · ⎢ 0 u₂₂ u₂₃ ⎥
⎣ a₃₁ a₃₂ a₃₃ ⎦ ⎣ l₃₁ l₃₂ 1 ⎦ ⎣ 0 0 u₃₃ ⎦

L holds the "elimination multipliers" — the numbers you multiply a row by before subtracting it from a row below during Gaussian elimination. U is the resulting upper-triangular matrix after all those subtractions.

The algorithm (Doolittle)

The entries are computed row-by-row:

u₁ⱼ = a₁ⱼ   (first row of U is just the first row of A)
lᵢ₁ = aᵢ₁ / u₁₁   (first column of L, below diagonal)
uᵢⱼ = aᵢⱼ − Σₖ lᵢₖ · uₖⱼ   (fill U, going right)
lᵢⱼ = (aᵢⱼ − Σₖ lᵢₖ · uₖⱼ) / uⱼⱼ   (fill L, going down)

The Σₖ sum runs over already-computed entries. In code, this is a double loop over i and j.

Why it is faster for repeated solves

For our Poisson equation A·x = b, once we have A = L·U:

L · U · x = b

We solve in two cheap steps:

  1. Forward substitution — solve L·y = b for y. Because L is lower-triangular, you start at the top row and work down:
    y₁ = b₁,  y₂ = b₂ − l₂₁·y₁,  y₃ = b₃ − l₃₁·y₁ − l₃₂·y₂, ...
  2. Back substitution — solve U·x = y for x. Because U is upper-triangular, you start at the bottom row and work up:
    xₙ = yₙ / uₙₙ,  xₙ₋₁ = (yₙ₋₁ − uₙ₋₁,ₙ·xₙ) / uₙ₋₁,ₙ₋₁, ...

Cost comparison (for our 9,751×9,751 matrix)

OperationCostTime (approx)
LU factorisation (once)O(n³) dense, O(n)–O(n²) sparse~0.5 s
Forward + back solve (each step)O(n) — only nonzeros touched~0.001 s
Naïve Gaussian elimination (each step)O(n³) — start from scratch~0.1 s
30,000 solves total1× factorise + 30k× solve~30 s
30,000 solves without LU30k× factorise~50 min

The speedup comes from reusing the factorisation. Our Laplacian matrix never changes — it is the same at step 1 and step 30,000 — so we pay the expensive factorisation cost once and get 30,000 cheap triangular solves.

Analogy: Factorising is like building a machine. Solving is like pressing the button. Building takes time; pressing the button is instant.

Appendix: CSR (Compressed Sparse Row)

A dense matrix stores every entry, including zeros:

Dense: 10,000 × 10,000 = 100,000,000 entries ≈ 800 MB

Our Laplacian matrix is sparse — each row has only ~5 nonzeros (the 5-point stencil). CSR stores only the nonzero values and their positions:

  • data — the nonzero values
  • indices — column index of each nonzero
  • indptr — where each row starts in data
CSR: ~50,000 entries ≈ 400 KB

This is a 2000× memory saving. Matrix-vector multiplication and LU factorisation are also much faster on sparse formats because they skip the zeros.

Analogy: A dense matrix is a printed spreadsheet with every cell filled. CSR is a Rolodex — it only stores the cards that actually have information on them.
