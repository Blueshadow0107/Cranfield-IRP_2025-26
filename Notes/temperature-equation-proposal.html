1. Overview — What changes

Currently the code prescribes viscosity directly via STRIP_NU_FRAC. There is no temperature field. This proposal adds:

WhatBeforeAfter
Viscosity model nu = NU_COLD * frac (prescribed) nu = NU_COLD * exp[β(1/T − 1/T_cold)]
Temperature field None T(x,y,t) solved via energy PDE
Heater control STRIP_NU_FRAC (direct) STRIP_HEAT_SOURCE [K/s] per strip
Vorticity diffusion nu * ∇²ω ∇·(ν∇ω) (conservative, face-flux)
Fields solved ψ, ω ψ, ω, T
Key reassurance: The Poisson matrix A for ∇²ψ = −ω is completely unchanged. It knows nothing about temperature or viscosity. Your pre-factorised LU solve stays exactly as-is.

2. Governing Equations

2.1 Energy equation (temperature transport)

∂T/∂t + u ∂T/∂x + v ∂T/∂y = α (∂²T/∂x² + ∂²T/∂y²) + S_T(x,y)
SymbolMeaningValue / Unit
TTemperature[K]
u, vVelocity from ψ[m/s]
αThermal diffusivity = k/(ρc_p)1.4 × 10⁻⁷ m²/s (water)
S_TVolumetric heater source[K/s] inside strips, 0 elsewhere

2.2 Vorticity equation (upgraded for variable ν)

∂ω/∂t + u ∂ω/∂x + v ∂ω/∂y = ∇·(ν∇ω)

The diffusion term is now the conservative divergence form. This is required because ν varies spatially (hot strips have lower ν, cold fluid has higher ν). The naive ν∇²ω would mishandle flux balance across strip edges.

Why conservative? Expanding ∇·(ν∇ω) gives ν∇²ω + ∇ν·∇ω. At a strip boundary where ν jumps by 5×, ∇ν is a delta function. The conservative discretisation handles this automatically via face fluxes. The extra term ∇ν·∇ω is included implicitly.

3. Arrhenius Viscosity Law

3.1 Formula

ν(T) = ν_cold · exp[ β (1/T − 1/T_cold) ]

3.2 Parameters

T_cold
300.0 K
Baseline (room temp). Fresh inlet fluid, wall temperature.
β (beta)
1900.0 K
Arrhenius sensitivity. Tunable. Higher = steeper viscosity drop per K.
ν_cold
1.0 × 10⁻⁶ m²/s
Baseline kinematic viscosity. Fixed.
ρ
998.0 kg/m³
Water density. Already in code.

3.3 Expected viscosity vs. temperature

T [K]ΔT [K]ν/ν_coldInterpretation
30001.000Baseline (cold fluid)
310+100.818~18% drop
320+200.670~33% drop
330+300.551~45% drop

With β = 1900 K, a strip heated to ~340 K gives roughly half the baseline viscosity. This is in the ballpark of water (which drops ~2× over 30–40 K).

Warning: The Arrhenius law is strictly for liquids. For gases, viscosity rises with temperature (Sutherland's law). Since our channel is water-like, Arrhenius is correct.

4. Stability Analysis

We are adding explicit thermal diffusion. The timestep must satisfy both the viscous and thermal diffusion limits.

4.1 Diffusion stability criteria

ModeFormulaLimit with current gridCurrent dt = 1e-4 s
Viscous dt < Δx² / (4 ν_max) 1.25 × 10⁻⁴ s (at ν_max = 5×10⁻⁶) SAFE (factor 1.25)
Thermal dt < Δx² / (4 α) 4.5 × 10⁻³ s VERY SAFE (factor 45)

Why is thermal so generous? Heat diffuses ~7× slower than momentum in water (Prandtl number Pr = ν/α ≈ 7). So the thermal limit is much weaker than the viscous limit. We are bottlenecked by viscosity, not temperature.

4.2 Advection (CFL)

Unchanged from before. CFL = U_max · dt / Δx ≈ 0.008. Safe.

4.3 What if we need stronger heating?

If STRIP_HEAT_SOURCE is very large, the temperature rises quickly but the explicit timestep is still limited by diffusion, not by the source term magnitude. The source term is explicit and local — it does not create a stability limit.

5. Boundary Conditions for Temperature

BoundaryConditionCodePhysical reason
Inlet (x = 0) Dirichlet: T = T_cold T[0, :] = T_COLD Fresh fluid at ambient temperature
Outlet (x = L) Zero-gradient: ∂T/∂x = 0 T[-1, :] = T[-2, :] Heat convected out, no back-diffusion
Bottom wall (y = 0) Dirichlet: T = T_cold T[:, 0] = T_COLD Isothermal wall (good conduction to ambient)
Top wall (y = H) Dirichlet: T = T_cold T[:, -1] = T_COLD Isothermal wall (good conduction to ambient)
Why isothermal walls? In a microchannel, the channel material (glass, silicon, metal) is typically much more thermally conductive than the thin fluid layer. The walls act as heat sinks held at ambient temperature. This also prevents runaway heating and gives a bounded steady-state temperature.

6. Discretization Details

6.1 Temperature equation

Same central-difference stencil as vorticity:

adv = u * (T[2:, 1:-1] - T[:-2, 1:-1]) / (2*DX) \
    + v * (T[1:-1, 2:] - T[1:-1, :-2]) / (2*DY)

diff = ALPHA * (
    (T[2:, 1:-1] - 2*T[1:-1, 1:-1] + T[:-2, 1:-1]) / DX**2 +
    (T[1:-1, 2:] - 2*T[1:-1, 1:-1] + T[1:-1, :-2]) / DY**2
)

rhs = -adv + diff + heat_mask[1:-1, 1:-1]
T[1:-1, 1:-1] += DT * rhs

6.2 Conservative vorticity diffusion (∇·(ν∇ω))

This is the tricky part. We compute fluxes across cell faces using face-averaged viscosity.

X-direction fluxes:

nu_e = 0.5 * (nu[2:-1, 1:-1] + nu[1:-2, 1:-1])   # east face
nu_w = 0.5 * (nu[1:-2, 1:-1] + nu[:-3,  1:-1])   # west face

flux_e = nu_e * (omega[2:-1, 1:-1] - omega[1:-2, 1:-1]) / DX
flux_w = nu_w * (omega[1:-2, 1:-1] - omega[:-3,  1:-1]) / DX

diff_x = (flux_e - flux_w) / DX

Y-direction fluxes (same pattern):

nu_n = 0.5 * (nu[1:-1, 2:-1] + nu[1:-1, 1:-2])
nu_s = 0.5 * (nu[1:-1, 1:-2] + nu[1:-1, :-3])

flux_n = nu_n * (omega[1:-1, 2:-1] - omega[1:-1, 1:-2]) / DY
flux_s = nu_s * (omega[1:-1, 1:-2] - omega[1:-1, :-3]) / DY

diff_y = (flux_n - flux_s) / DY

6.3 The indexing problem

Face averaging shrinks the valid domain by one extra node in each direction:

Array sliceValid x-rangeValid y-range
omega[1:-1, 1:-1]1 … NX−11 … NY−1
omega[2:-1, 1:-1] (east)2 … NX−11 … NY−1
omega[:-3, 1:-1] (west)0 … NX−31 … NY−1
diff_x result1 … NX−21 … NY−1
diff_y result1 … NX−11 … NY−2
Intersection2 … NX−22 … NY−2

The final valid interior for the RHS is [2:-2, 2:-2] — two nodes away from every boundary. This means the outermost interior ring is not updated by the vorticity RHS; it is held by the boundary conditions.

Trade-off: With NY = 50, 2:-2 gives 46 valid y-nodes. The two excluded rows near walls are handled by Thom's formula (wall vorticity) and zero-gradient open boundaries. For a 201×51 grid, losing 2 nodes in each direction is negligible for the physics.

7. Code Skeleton

7.1 New parameters

# --- THERMAL PARAMETERS ---
T_COLD = 300.0              # baseline temperature [K]
ALPHA = 1.4e-7              # thermal diffusivity [m^2/s]
BETA = 1900.0               # Arrhenius sensitivity [K]

# Per-strip heater source [K/s]. 0 = off.
STRIP_HEAT_SOURCE = [50.0, 50.0, 50.0, 50.0]

7.2 New arrays & mask

T = np.ones((NX + 1, NY + 1)) * T_COLD
nu = np.ones((NX + 1, NY + 1)) * NU_COLD   # will be updated each step

# Build heater mask (same geometry as strips)
heat_mask = np.zeros((NX + 1, NY + 1))
for i, q in enumerate(STRIP_HEAT_SOURCE):
    x0 = STRIP_X_STARTS[i]
    heat_mask[x0:x0+STRIP_WIDTH+1,
              STRIP_Y_START:STRIP_Y_START+STRIP_HEIGHT+1] = q

7.3 New functions

def viscosity_from_temperature(T):
    """Arrhenius: ν = ν_cold * exp[β(1/T - 1/T_cold)]"""
    return NU_COLD * np.exp(BETA * (1.0 / T - 1.0 / T_COLD))

def temperature_rhs(T, u, v):
    """Compute dT/dt = -u·∇T + α∇²T + heat_source on interior."""
    # Advection (central differences)
    dTdx = (T[2:, 1:-1] - T[:-2, 1:-1]) / (2.0 * DX)
    dTdy = (T[1:-1, 2:] - T[1:-1, :-2]) / (2.0 * DY)
    adv = u * dTdx + v * dTdy

    # Diffusion (5-point Laplacian)
    diff = ALPHA * (
        (T[2:, 1:-1] - 2*T[1:-1, 1:-1] + T[:-2, 1:-1]) / (DX*DX) +
        (T[1:-1, 2:] - 2*T[1:-1, 1:-1] + T[1:-1, :-2]) / (DY*DY)
    )

    rhs = np.zeros_like(T)
    rhs[1:-1, 1:-1] = -adv + diff + heat_mask[1:-1, 1:-1]
    return rhs

def vorticity_rhs_variable_nu(omega, psi, nu):
    """Conservative ∇·(ν∇ω) diffusion + advection."""
    # Velocities on interior
    u = (psi[1:-1, 2:] - psi[1:-1, :-2]) / (2.0 * DY)
    v = -(psi[2:, 1:-1] - psi[:-2, 1:-1]) / (2.0 * DX)

    # Advection
    dwdx = (omega[2:, 1:-1] - omega[:-2, 1:-1]) / (2.0 * DX)
    dwdy = (omega[1:-1, 2:] - omega[1:-1, :-2]) / (2.0 * DY)
    adv = u * dwdx + v * dwdy

    # --- Conservative diffusion: ∇·(ν∇ω) ---
    # X-face fluxes
    nu_e = 0.5 * (nu[2:-1, 1:-1] + nu[1:-2, 1:-1])
    nu_w = 0.5 * (nu[1:-2, 1:-1] + nu[:-3,  1:-1])
    flux_e = nu_e * (omega[2:-1, 1:-1] - omega[1:-2, 1:-1]) / DX
    flux_w = nu_w * (omega[1:-2, 1:-1] - omega[:-3,  1:-1]) / DX
    diff_x = (flux_e - flux_w) / DX

    # Y-face fluxes
    nu_n = 0.5 * (nu[1:-1, 2:-1] + nu[1:-1, 1:-2])
    nu_s = 0.5 * (nu[1:-1, 1:-2] + nu[1:-1, :-3])
    flux_n = nu_n * (omega[1:-1, 2:-1] - omega[1:-1, 1:-2]) / DY
    flux_s = nu_s * (omega[1:-1, 1:-2] - omega[1:-1, :-3]) / DY
    diff_y = (flux_n - flux_s) / DY

    rhs = np.zeros_like(omega)
    # Valid region is [2:-2, 2:-2] due to face averaging
    rhs[2:-2, 2:-2] = -adv[1:-1, 1:-1] + diff_x[1:-1, 1:-1] + diff_y[1:-1, 1:-1]
    return rhs

7.4 New time loop order

for n in range(NT):
    t = n * DT

    # --- 1. Inlet BCs ---
    psi_in = inlet_psi_profile(t)
    psi_bcs = {
        'left': psi_in,
        'right': psi_in,          # fully developed
        'bottom': np.zeros(NX + 1),
        'top': np.ones(NX + 1) * psi_in[-1]
    }

    # --- 2. Solve Poisson for ψ (LU factor, unchanged) ---
    psi = solve_streamfunction(omega, psi_bcs)

    # --- 3. Compute velocities ---
    u = (psi[1:-1, 2:] - psi[1:-1, :-2]) / (2.0 * DY)
    v = -(psi[2:, 1:-1] - psi[:-2, 1:-1]) / (2.0 * DX)

    # --- 4. Update temperature ---
    rhs_T = temperature_rhs(T, u, v)
    T[1:-1, 1:-1] += DT * rhs_T[1:-1, 1:-1]
    # Temperature BCs
    T[0, :]  = T_COLD      # inlet
    T[-1, :] = T[-2, :]    # outlet zero-gradient
    T[:, 0]  = T_COLD      # bottom wall
    T[:, -1] = T_COLD      # top wall

    # --- 5. Update viscosity from temperature ---
    nu = viscosity_from_temperature(T)

    # --- 6. Wall vorticity (Thom's formula) ---
    omega[:, 0]  = -2.0 * psi[:, 1] / (DY*DY)
    omega[:, -1] = -2.0 * (psi[:, -2] - psi[:, -1]) / (DY*DY)

    # --- 7. Open boundaries (zero-gradient) ---
    omega[0, :]  = omega[1, :]
    omega[-1, :] = omega[-2, :]

    # --- 8. Update vorticity ---
    rhs_omega = vorticity_rhs_variable_nu(omega, psi, nu)
    omega[2:-2, 2:-2] += DT * rhs_omega[2:-2, 2:-2]

8. Coupling Logic

The three fields are coupled in a one-way staggered cycle within each timestep:

ω(n) → ∇²ψ(n+½) = −ω(n) → (u,v)(n+½)

(u,v)(n+½) → T(n+1) = T(n) + dt · RHS_T

T(n+1) → ν(n+1) = fArrhenius(T(n+1))

ν(n+1) → ω(n+1) = ω(n) + dt · RHS_ω(ν(n+1))

This is operator splitting — first-order accurate in time, consistent with the explicit Euler method. No simultaneous solve is needed.

Why is this valid? The physical timescales are well-separated:
  • Flow response (advection): τ_flow ≈ L/U ≈ 5 s
  • Thermal diffusion: τ_thermal ≈ H²/α ≈ 89 s
  • Viscous diffusion: τ_viscous ≈ H²/ν ≈ 6 s
With dt = 0.1 ms, we resolve all three processes. The splitting error is negligible compared to the first-order time integration.
