5. Data Flow — Working Solver

cylinder_array_solver.py

Initialize:
  psi = parabolic inlet profile
  omega = from psi via finite differences
  obs_mask = boolean array from CYLINDERS config

For each time step:
  1. solve_streamfunction(omega, psi_bcs)
     └── PoissonLU.solve(−omega_interior)  [sparse direct solve]
  
  2. interior_velocities(psi)
     └── u = dpsi/dy, v = −dpsi/dx  [central differences]
  
  3. update_obstacle_vorticity(omega, psi)
     └── Thom's formula at obs_boundary cells
  
  4. vorticity_rhs(omega, u, v, nu)
     └── advection + conservative diffusion
  
  5. omega += DT * rhs_omega  [explicit Euler]

Post-process:
  FFT probe history → dominant freq, amplitude, std

6. Data Flow — Broken Primitive Solver

primitive_ns_solver.py (latest v7)

Initialize:
  u = 0, v = 0, p = 0  (fluid at rest)
  alpha_u, alpha_v = interpolate alpha_cell to faces

Pre-build matrices:
  helm_u = splu(I − 0.5·dt·ν·L_u)   [Helmholtz for implicit diffusion]
  helm_v = splu(I − 0.5·dt·ν·L_v)
  poisson_lu = splu(D·G matrix)      [pressure Poisson]

For each time step:
  1. Predictor (Crank-Nicolson diffusion)
     ├── Interpolate v→u_faces, u→v_faces
     ├── Compute advection_u, advection_v  [upwind]
     ├── Compute laplacian_u, laplacian_v
     ├── rhs_u = u + dt·(−adv − α·u) + 0.5·dt·ν·L(u)
     ├── u* = helm_u.solve(rhs_u)
     └── Apply velocity BCs to u*, v*
  
  2. Pressure Poisson
     ├── div_u_star = divergence(u*, v*)
     ├── rhs_p = (ρ/dt) · div_u_star
     └── p = poisson_lu.solve(rhs_p)
  
  3. Corrector (interior faces only)
     ├── u = u* − (dt/ρ)·dp/dx
     ├── v = v* − (dt/ρ)·dp/dy
     └── Boundary faces keep u*, v* values

Problem: div(u*) after step 2 is O(1) at boundaries
         → pressure gradient is O(10⁵)
         → corrector creates O(10⁻²) velocities
         → next predictor sees larger gradients
         → exponential blowup
