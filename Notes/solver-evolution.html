v7 — Smaller Time Step (dt = 1×10⁻⁵)

ChangeResult
Reduce dt by 5× to improve stabilityNaN by step 500 (same physical time)

Key finding: The instability is structural, not a CFL violation. Error per physical time t is independent of dt because explicit Euler on an unstable mode grows as e^(λt).

Root cause identified: The projection method on a staggered MAC grid with inlet/outlet boundaries requires div(∇p) = ∇²p exactly. This holds for interior cells but fails at boundaries because the pressure gradient is not defined at boundary faces (they are not corrected). The residual divergence accumulates exponentially.

Root cause: The explicit advection term u·∂ω/∂x + v·∂ω/∂y sees the sharp vorticity gradient at obstacle boundaries and explodes. The original solver avoids this by using Thom's formula to explicitly set boundary vorticity — without that discrete boundary treatment, the gradient is unresolvable by explicit time-marching.

4. The Old Assignment Method (Working)

Found in backup drive: assignments-ARCHIVED/INCOMP/

PropertyValue
MethodArtificial Compressibility (Chorin, 1967)
GridCollocated (u, v, p at same points)
AdvectionUpwind (u[i] − u[i−1])/dx
ViscousCentral differences
Pressurep_new = p_old − β·dt·div(u) — no Poisson solve
StabilityArtificial viscosity 0.01·ν + adaptive under-relaxation

Why it works: No global Poisson solve means pressure errors are local. Upwind advection handles sharp gradients. The method converges to steady state via pseudo-time stepping.

Trade-off: Artificial compressibility is a pseudo-time method — it converges to steady state, but the transient is not physically time-accurate. For watching the flow "develop from rest," this is a limitation.

6. Open Decisions

  1. Steady-state vs time-accurate? If steady-state is enough, artificial compressibility (from assignment) is a proven path.
  2. Discrete vs continuous obstacles? The discrete ψ–ω solver works and can be framed theoretically as the resolved microscale per Allaire 1991 homogenization.
  3. Brinkman drag? To make Brinkman work, we would need either implicit advection (nonlinear solve per step) or a much smoother α(x,y) field with no sharp gradients.
Recommendation: Given MSc time constraints, the pragmatic path is to use the working discrete-obstacle ψ–ω solver and frame it in the thesis as the resolved limit of a porous medium. The Brinkman transition can be discussed theoretically (homogenization) without requiring a working continuous solver.
